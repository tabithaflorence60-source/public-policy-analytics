# Policy Evaluation

Policy evaluation asks whether an intervention changed outcomes, for whom, by how much, and under what conditions.

## 1. From activity to outcomes

Public programs often report activities and outputs when the more important question is whether outcomes actually changed. A useful distinction is:

- **inputs** — resources invested
- **activities** — what the program does
- **outputs** — immediate products or services delivered
- **outcomes** — changes in behavior, performance, access, welfare, or environmental conditions
- **impacts** — changes attributable to the intervention rather than to other causes

## 2. The counterfactual

The central evaluation problem is that we cannot observe the same unit both with and without the intervention at the same time. Evaluation designs therefore construct a credible comparison or counterfactual.

Simple before-after or with-without comparisons can be misleading when groups differ systematically or when other changes occur at the same time.

## 3. Evaluation designs

Common approaches include:

- randomized experiments when feasible and ethical
- matched comparison groups
- before-after comparisons with strong caveats
- difference-in-differences
- panel-data approaches
- regression adjustment
- interrupted time series

The method should follow the policy question and the data-generating process, not the other way around.

## 4. Difference-in-differences

Difference-in-differences compares the change in outcomes for a treated group with the change for a comparison group. A formal specification will be added only after the data structure, treatment timing, comparison group, assumptions, and code have been checked.

## 5. Theory of change

Strong evaluation requires more than a statistical estimator. A theory of change identifies:

- how the intervention is expected to work
- which actors change behavior
- which intermediate outcomes should occur
- which contextual factors can enable or block the mechanism
- where spillovers may occur

This matters especially for sustainability policy because institutional capacity, geography, political economy, and infrastructure can shape whether the same intervention works differently across places.

## 6. Energy and sustainability applications

Possible evaluation questions include:

- Did a renewable-energy incentive increase adoption?
- Did an electrification program improve access or affordability?
- Did grid investment reduce outage frequency or duration?
- Did a community-benefit program improve participation or trust?
- Did a policy instrument reduce emissions without shifting burdens elsewhere?

## 7. Interpreting results

A statistically significant estimate is not the end of the analysis. Evaluation should also examine:

- effect size
- cost-effectiveness
- distributional consequences
- implementation fidelity
- spillovers
- external validity
- institutional context

## 8. Research connection

Policy evaluation is where the portfolio moves from describing policy to testing what works. It supports future empirical work on energy-policy instruments, infrastructure investment, access, resilience, and comparative implementation across Kenya and Portugal.
